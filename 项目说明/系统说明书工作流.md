# 课题组系统说明书 — 可复用工作流

> 目标：为三套系统各产出一份飞书文档说明书，让老师快速理解物理连接链路和数据链路。
> 原则：物理连接 + 数据链路为主，原理点到为止，不展开算法细节。
> 输出：三份独立的飞书文档，每份包含两张 draw.io 图（物理连接图 + 数据链路图）。

---

## 工作流总览（对每套系统重复一次）

```
┌─────────────────────────────────────────────────────┐
│  Step 1: 信息收集（填模板）                          │
│  ↓                                                   │
│  Step 2: 绘制 draw.io 物理连接链路图                  │
│  ↓                                                   │
│  Step 3: 用户修改物理连接图 → 确认                    │
│  ↓                                                   │
│  Step 4: 绘制 draw.io 数据链路图                      │
│  ↓                                                   │
│  Step 5: 用户修改数据链路图 → 确认                    │
│  ↓                                                   │
│  Step 6: 创建飞书文档 + 插入图片 + 撰写文字            │
│  ↓                                                   │
│  Step 7: 用户验收                                     │
└─────────────────────────────────────────────────────┘
```

## Step 2-3: 物理连接链路图（draw.io）

### 图纸规范

- **画布尺寸**：横向 A4（1169×826px）
- **风格**：白底、彩色方框、实线箭头
- **包含元素**：
  - 所有物理设备（相机、云台、镜头、电脑、交换机等）
  - 连接线标注连接类型（网线/RJ45、RS485/串口、USB等）
  - 数据方向箭头
  - 设备标注名称和型号（如已知）
- **不包含**：软件模块（留到数据链路图）

### draw.io 模板结构

```
[相机] ──网线──→ [交换机] ──网线──→ [电脑]
[云台] ──RS485──→ [串口/USB转接] ──→ [电脑]
                                         ↑
                                    [镜头] (通过相机SDK控制)
```

### 输出格式
- draw.io XML 文件，保存到 `说明文档/drawio/系统名_物理连接.drawio`
- 用户在 draw.io 中打开修改 → 确认后导出 PNG

---

## Step 4-5: 数据链路图（draw.io）

### 图纸规范

- **画布尺寸**：横向 A3（1654×1169px）或自动
- **风格**：白底、彩色方框（按功能分色）、实线/虚线箭头
- **包含元素**：
  - 软件模块（方框，按功能分色）
  - 线程边界（虚线框，标注线程名）
  - 数据流（实线箭头，标注数据类型）
  - 控制流（虚线箭头，标注控制指令）
  - 信号/槽连接（Qt信号机制）
  - 外部接口（相机SDK、串口、文件系统等）
- **颜色约定**：
  - 🔵 蓝色：数据采集/输入模块
  - 🟢 绿色：数据处理/算法模块
  - 🟠 橙色：控制/执行模块
  - 🟣 紫色：存储/记录模块
  - ⚪ 灰色：配置/管理模块
  - 🔴 红色边框：未成功运行的模块

### draw.io 模板结构

```
┌─────────────── 主线程 ───────────────────┐
│  [ConfigManager] → [MainWindow]          │
│       ↓                    ↑              │
│  [DeviceManager]     [CaptureManager]    │
│       ↓                    ↓              │
│  [DecodeThread] → [ImageProcessor]       │
│       ↓                    ↓              │
│  [RecordThread]     [TrackingController]  │
│       ↓                    ↓              │
│  [DataRecorder]     [PTZController]       │
└──────────────────────────────────────────┘
         ↕                    ↕
   [相机SDK]              [串口/RS485]
```

### 输出格式
- draw.io XML 文件，保存到 `说明文档/drawio/系统名_数据链路.drawio`
- 用户在 draw.io 中打开修改 → 确认后导出 PNG

## Step 6: 飞书文档结构模板

### 文档标题
`【系统说明书】系统名称`

### 文档结构

```
一、系统概述
   - 一段话说明系统用途、核心功能、运行状态
   - 列出关键硬件和软件模块

二、物理连接链路
   【插入：物理连接链路图 PNG】
   - 逐条解释图中每条连接线
   - 标注接口类型、协议、波特率等关键参数

三、数据链路
   【插入：数据链路图 PNG】
   - 按数据流向逐步讲解（从传感器到最终输出）
   - 区分视频数据流、控制指令流、数据记录流
   - 简要提及关键算法原理（1-2句话，不展开）

四、运行流程
   - 启动顺序（先开什么、后开什么）
   - 关键操作步骤（连接→配置→运行→停止）
   - 注意事项

五、运行状态
   - 哪些环节已验证成功
   - 哪些环节存在问题（如有）
   - 问题表现和已尝试的排查方向

六、简要原理（可选，每项不超过3句话）
   - 视频解码：FFmpeg H.264解码
   - 目标跟踪：DSST相关滤波 + 卡尔曼滤波（仅适用系统三）
   - PTZ控制：Pelco-D协议
   - 镜头控制：Univision SDK
```

### 飞书文档操作流程

1. 使用 `lark-doc` skill 创建飞书文档
2. 使用 `lark-drive` skill 上传 PNG 图片到云盘
3. 使用 `lark-doc` skill 在文档中插入图片
4. 使用 `lark-doc` skill 逐节写入文字内容
