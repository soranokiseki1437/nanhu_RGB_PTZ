## 一、 基准模型规格与技术指标

基准模型采用微软亚洲研究院开源的经典轻量化单目标跟踪网络 LightTrackM（ICCV 2021 Oral / IEEE TPAMI 2022），网络拓扑基于神经架构搜索（NAS）得到的纯深度可分离卷积（DW-Conv）与互相关预测头：

| 评估维度 | 规格指标 | 说明 |
| :--- | :--- | :--- |
| **基础骨干网络** | MobileNet-NAS 深度可分离卷积骨干 | 纯 DW-Conv 结构，无动态算子 |
| **模型参数量** | 1.60 M | 全网络权重总容量约 7.68 MB |
| **计算量 (FLOPs)** | 0.58 GFLOPs | 搜索帧前向计算量 |
| **纯模型推理耗时** | 2.1 ms (RTX 5070) | 对应纯算力吞吐约 476 FPS |
| **本地实测基准 (Anti-UAV 20 组航迹)** | AUC 52.24% / DP@20 66.06% / 跟丢率 14.16% | 24,919 帧 OPE 协议单程评测指标 |
| **权重文件来源** | `D:\PyProjects\SOT_Tracking_Baselines\checkpoints\lighttrack\LightTrackM.pth` | 官方全量预训练权重 |

## 二、 纯静态 ONNX 计算图定义与张量规范

为满足 DirectML 与 RKNN 硬件算子直通要求，模型解耦为两组纯静态计算图导出，输入输出维度严格锁定：

```
                    ┌────────────────────────────────────────────────────────┐
                    │          LightTrack 原版双分支静态计算图与接口          │
                    └────────────────────────────────────────────────────────┘
                                                 │
             ┌───────────────────────────────────┴───────────────────────────────────┐
             ▼                                                                       ▼
    【模板分支 (Template Branch)】                                          【搜索分支 (Search Branch)】
       静态输入: 1x3x127x127                                                   静态输入: 1x3x255x255
             │                                                                       │
     [LightTrack 骨干 (DW-Conv)]                                             [LightTrack 骨干 (共享权重)]
             │                                                                       │
     输出静态模板特征 z: 1x96x8x8                                            输出静态搜索特征 x: 1x96x16x16
             │ (首帧截取后常驻显存/NPU)                                              │ (高频逐帧抽取)
             └───────────────────────────────────┬───────────────────────────────────┘
                                                 │
                                                 ▼
                             【LightTrack 互相关匹配与预测头】
                             • 输入: 模板特征 z (1x96x8x8) + 搜索特征 x (1x96x16x16)
                             • 输出分类响应图: 1x1x16x16 (目标中心置信度)
                             • 输出边界回归图: 1x4x16x16 (边界偏移量 l, t, r, b)
```

### 2.1 模板提取网络 (`models/lighttrack_template.onnx`)
- **输入张量**：`template_img`，类型 `float32`，形状 `[1, 3, 127, 127]`，数值归一化至 $[0.0, 1.0]$；
- **输出张量**：`template_feat`，类型 `float32`，形状 `[1, 96, 8, 8]`；
- **运行特征**：目标初始化时调用 1 次，特征张量驻留显存/内存缓存。

### 2.2 搜索与预测网络 (`models/lighttrack_search.onnx`)
- **输入张量 1**：`search_img`，类型 `float32`，形状 `[1, 3, 255, 255]`，数值归一化至 $[0.0, 1.0]$；
- **输入张量 2**：`template_feat`，类型 `float32`，形状 `[1, 96, 8, 8]`；
- **输出张量 1**：`cls_score`，类型 `float32`，形状 `[1, 1, 16, 16]`，中心置信度响应；
- **输出张量 2**：`reg_dist`，类型 `float32`，形状 `[1, 4, 16, 16]`，回归距离向量 $(l, t, r, b)$；
- **运行特征**：逐帧高频调用，纯网络推理时延 $\le 2.2\text{ ms}$。

## 三、 C++ 侧工程接入与系统闭环集成

### 3.1 C++ 跟踪器封装接口 (`OnnxSotTracker`)

```cpp
class OnnxSotTracker {
public:
    OnnxSotTracker();
    ~OnnxSotTracker();

    // 初始化 DirectML 执行提供者，加载模板与搜索 ONNX
    bool init(const std::string& templateOnnx, const std::string& searchOnnx);

    // 接收初始目标框，截取模板并提取特征缓存
    bool initTemplate(const cv::Mat& frame, const cv::Rect2d& initBbox);

    // 逐帧连续跟踪，输出当前帧预测边界框与置信度
    bool track(const cv::Mat& frame, cv::Rect2d& outBbox, float& outConfidence);

private:
    // 上下文扩展（Context padding）裁剪与双线性缩放
    cv::Mat getSubwindow(const cv::Mat& img, cv::Point2f center, int modelSz, int originalSz);

    // 预测响应图解析、余弦窗惩罚与坐标还原
    cv::Rect2d decodeBbox(const float* regData, const float* clsData, cv::Point2f center, float scale);
};
```

### 3.2 坐标解码与前后处理规范
1. **搜索区域尺寸计算**：
   $$s_z = \sqrt{(w + 2p) \times (h + 2p)}, \quad p = \frac{w + h}{4}$$
   搜索窗口实际裁剪边长为 $s_x = 2 \times s_z$，统一通过双线性插值缩放至 $255\times 255\times 3$；
2. **预测结果解码**：
   在 $16\times 16$ 分类图上寻找置信度峰值点 $(r, c)$，回归距离 $(l, t, r, b)$ 经过尺度比例映射恢复至原图坐标：
   $$\text{cx} = \text{target\_cx} + (c - 8) \times \text{stride} \times \frac{s_x}{255}$$
   $$\text{cy} = \text{target\_cy} + (r - 8) \times \text{stride} \times \frac{s_x}{255}$$
