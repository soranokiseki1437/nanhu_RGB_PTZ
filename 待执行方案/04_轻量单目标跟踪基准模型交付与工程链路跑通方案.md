## 二、纯静态 ONNX 计算图定义

| 文件 | 输入 | 输出 |
| :--- | :--- | :--- |
| `models/lighttrack_template.onnx` | `template_img` `[1,3,127,127]` float32，RGB，[0,1] | `template_feat` `[1,96,8,8]` |
| `models/lighttrack_search_256.onnx` | `search_img` `[1,3,256,256]`；`template_feat` `[1,96,8,8]` | `cls_logit` `[1,1,16,16]`；`reg_dist` `[1,4,16,16]`（l,t,r,b，搜索图像素） |
| `models/lighttrack_search_288.onnx` | `search_img` `[1,3,288,288]`；`template_feat` `[1,96,8,8]` | `cls_logit` `[1,1,18,18]`；`reg_dist` `[1,4,18,18]` |

- 模板分支在目标初始化与 YOLO 重捕成功时运行，特征驻留内存；搜索分支逐帧运行；
- ImageNet 均值方差归一化固化于计算图，输入为 [0,1] RGB 平面；
- 全部为 opset 17 静态图，不含动态序列展开与自定义算子。

## 三、C++ 侧工程接入

| 层次 | 内容 |
| :--- | :--- |
| 抽象接口 | `ISotTracker`（`ensureLoaded` / `init` / `track` / `peek` / `setState`） |
| 实现 | `OnnxSotTracker`（ONNX Runtime C-API + DirectML，三个常驻 Session，预处理/后处理与 `lighttrack.py` 逐行对齐） |
| 双内核 | `ObjectTracker` 通过 `TrackingKernel`（`KERNEL_DSST` / `KERNEL_LIGHTTRACK`）分派；`TrackingController` 注入共享引擎；`MainWindow` 提供 `comboTrackKernel` |
| AMFT 接线 | LightTrack 的 sigmoid 分类峰值经 `psr = 5 + 20·cls` 映射送入 `AMFTEvaluator`；四态状态机沿用；YOLO 重捕成功后以新框重算模板特征 |
| 离线验证 | `tools/test_sot_tracker.cpp`：20 组序列闭环评测、与 Python 参考的开环回放、`--amft` 阈值标定数据输出 |

详细公式、接口与改造点见实施规范。
