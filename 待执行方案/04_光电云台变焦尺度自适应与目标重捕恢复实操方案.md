## 一、 方案定位与物理问题定义

在光电吊舱无人机地对空跟踪外场实测与序列验证中，目标运动与光学变倍呈现以下物理特征：
1. **光学变焦导致目标尺度超限突变**：长焦连续光学放大（Zoom In）时，目标像素尺寸在数帧内成倍放大。传统离散尺度滤波器（单帧步长 1.05）无法跟进该速率，导致平移采样窗严重小于真实目标，平移特征退化并触发失锁。
2. **脱靶后目标重捕空间约束失配**：目标在长焦视场内脱靶丢失后，卡尔曼滤波航位推算发散，目标重新进入视野的位置与推算位置存在大视场偏差。硬编码的局部搜索半径截断导致全图检测结果被算法逻辑主动丢弃。
3. **全图检索下的伪目标误劫持风险**：若彻底放开搜索半径，地面长条杂波、建筑物反光或多目标场景极易产生单帧高置信度虚警，引发错误重捕与目标误劫持（ID Switch）。
4. **控制链路与状态机逻辑短路**：单目标框选模式下关闭了深度检测协同链路，变焦校准信号与全局重检测链路无法被调度；且长时间丢失后重捕时若直接更新卡尔曼滤波，位置瞬态跳变会产生巨大虚假速度，引发机电伺服剧烈甩动冲击。

本方案针对上述物理与工程缺陷，规范变焦自适应尺度校准机制、防误劫持分级重捕状态机以及云台伺服平稳软启动机制。

## 二、 系统架构与状态机流转

系统感知与重捕控制由跟踪内核（LightTrack / DSST）、三维评估器（AMFT）、全图检测器（YOLO）与伺服控制器协同完成：

```mermaid
flowchart TD
    Frame[视频输入 BGR 图像帧] --> Update[ObjectTracker::update]
    Update --> StateCheck{当前跟踪状态}
    
    StateCheck -->|正常跟踪态 NORMAL| NormalBranch[运行单目标跟踪内核]
    NormalBranch --> ZoomCheck{变焦中或变焦完成?}
    ZoomCheck -->|是 (步进/终态)| CalibZoom[执行 calibrateScaleOnZoom 定向检测]
    ZoomCheck -->|否| RegularUpdate[常规回归/尺度平滑更新]
    CalibZoom --> ResetTemplate[强制重新提取模板与更新真实尺寸]
    
    StateCheck -->|脱靶异常态 OCCLUDED / LOST| RecoveryBranch[进入 tryDetectAndRecover]
    RecoveryBranch --> LevelCheck{失锁阶段判断}
    LevelCheck -->|失锁 <= 15 帧 OCCLUDED| LocalSearch[第一级: 时空局部动网格搜索]
    LevelCheck -->|失锁 > 15 帧 LOST| GlobalSearch[第二级: 全图无距离约束搜索 + 长宽比过滤]
    
    LocalSearch --> CandidateMatch{几何/相似度评分校验}
    GlobalSearch --> CandidateMatch
    
    CandidateMatch -->|连续两帧确认命中| Reacquired[重捕恢复态 REACQUIRED]
    CandidateMatch -->|未命中 / 单帧抖动| Extrapolate[卡尔曼匀速外推 / 伺服停稳]
    
    Reacquired --> ResetState[重置内核模板 / 清零KF速度 / 重启PID软启动]
```

### 跟踪与重捕状态机定义

| 状态枚举值 | 判定条件 | 算法行为 | 伺服动作 |
| :--- | :--- | :--- | :--- |
| `TRACK_NORMAL` | $R_t \ge \tau_t$ 且未检测到变焦信号 | 运行单目标跟踪内核，输出目标中心与宽高 | 速度前馈 + PID 闭环跟踪 |
| `TRACK_ZOOM_CALIBRATING` | 变焦中（每 300ms 步进）或收到 `zoomFinished` | 暂停常规模型更新，执行定向尺度重校准（带 5 帧重试） | 维持上一帧平滑速度伺服 |
| `TRACK_OCCLUDED` | 连续 4 帧 $R_t < \tau_t$（失锁 $\le 15$ 帧） | 冻结跟踪内核更新，启动**第一级：时空局部重捕** | 卡尔曼滤波匀速外推，限制速度 |
| `TRACK_LOST` | 连续失锁 $> 15$ 帧 | 降频至 3 FPS，启动**第二级：全图重捕 + 2帧时序确认** | 云台制动停稳（输出速度 0） |
| `TRACK_REACQUIRED` | 连续两帧命中目标并完成门限校验 | 调用 `reinitKernel` 重置模板，更新真实尺度 | **速度清零软启动**，重置 PID 积分 |

## 三、 变焦（Zoom）尺度自适应与重校准实现规范

### 3.1 变焦信号时序与双触发机制
消除框选模式对变焦校准信号的屏蔽，并解决长时按住变焦按键过程中的中途失锁问题：

1. **信号下发链路**：
   `LensManager` 在变焦持续期间每 300ms 发射步进信号，并在变焦动作结束（松开按键）时发射 `zoomFinished` 终态信号 ➔ 经 `TrackingController::triggerScaleCalibration` ➔ `ObjectTracker::triggerScaleCalibration`。
2. **标志位置位契约**：
   `ObjectTracker::triggerScaleCalibration()` 将原子布尔标志 `m_needScaleCalibration` 置为 `true`，并初始化重试计数器 `m_zoomCalibRetries = 5`。
3. **主循环插桩位置**：
   在 `ObjectTracker::update` 起始阶段前置执行，未命中时递减重试计数：

```cpp
if (m_needScaleCalibration || m_zoomCalibRetries > 0) {
    if (calibrateScaleOnZoom(image)) {
        m_needScaleCalibration = false;
        m_zoomCalibRetries = 0;
    } else {
        if (m_zoomCalibRetries > 0) m_zoomCalibRetries--;
        if (m_zoomCalibRetries == 0) m_needScaleCalibration = false;
    }
}
```

### 3.2 变焦尺度重校准函数实现规范 (`calibrateScaleOnZoom`)

```cpp
bool ObjectTracker::calibrateScaleOnZoom(const cv::Mat& image)
{
    if (!m_detector || !m_detector->isLoaded()) {
        return false;
    }

    const float kfX = m_kf.x[0];
    const float kfY = m_kf.x[1];

    std::vector<DetectionBox> detections = m_detector->detect(image);
    if (detections.empty()) {
        return false;
    }

    float bestScore = 0.0f;
    DetectionBox bestBox;
    bool matched = false;

    // 变焦工况下，允许目标尺寸缩放 0.1x ~ 10.0x
    const float currentAspect = (m_targetH > 1.0f) ? (m_targetW / m_targetH) : 1.0f;
    const float zoomSearchRadius = std::max(image.cols, image.rows) * 0.45f;

    for (const auto& det : detections) {
        if (det.confidence < 0.25f) continue;

        const float cx = det.rect.x() + det.rect.width() * 0.5f;
        const float cy = det.rect.y() + det.rect.height() * 0.5f;
        const float dist = std::sqrt((cx - kfX) * (cx - kfX) + (cy - kfY) * (cy - kfY));
        if (dist > zoomSearchRadius) continue;

        const float detAspect = (det.rect.height() > 1.0f) ? 
            (static_cast<float>(det.rect.width()) / det.rect.height()) : 1.0f;
        const float aspectDiff = std::abs(detAspect - currentAspect) / std::max(currentAspect, 0.1f);
        if (aspectDiff > 1.2f) continue; // 排除长宽比畸变过大目标（如地面长条杂波）

        const float spatialWeight = 1.0f - (dist / zoomSearchRadius);
        const float aspectWeight = std::max(0.1f, 1.0f - aspectDiff * 0.6f);
        const float score = det.confidence * spatialWeight * aspectWeight;

        if (score > bestScore) {
            bestScore = score;
            bestBox = det;
            matched = true;
        }
    }

    if (!matched || bestScore < 0.20f) {
        return false;
    }

    const cv::Rect newRoi(static_cast<int>(std::round(bestBox.rect.x())),
                          static_cast<int>(std::round(bestBox.rect.y())),
                          static_cast<int>(std::round(bestBox.rect.width())),
                          static_cast<int>(std::round(bestBox.rect.height())));
    const cv::Rect clampedRoi = newRoi & cv::Rect(0, 0, image.cols, image.rows);

    if (clampedRoi.width < 6 || clampedRoi.height < 6) {
        return false;
    }

    // 重新初始化模板与内核状态
    if (!reinitKernel(image, clampedRoi)) {
        return false;
    }

    m_posX = clampedRoi.x + clampedRoi.width * 0.5f;
    m_posY = clampedRoi.y + clampedRoi.height * 0.5f;
    m_targetW = static_cast<float>(clampedRoi.width);
    m_targetH = static_cast<float>(clampedRoi.height);
    m_currentScale = 1.0f;

    kfUpdate(m_posX, m_posY);
    m_evaluator.init(cv::Rect2f(clampedRoi.x, clampedRoi.y, clampedRoi.width, clampedRoi.height));

    return true;
}
```

## 四、 防误劫持分级目标重捕算法与伺服软启动规范

### 4.1 重捕触发架构调整
解除手动框选模式下对全局检测的禁用，建立防虚警重捕闭环：
1. **模式统一**：移除在 `MainWindow` 框选结束时下发的 `setRedetectionEnabled(false)`，统一由 `AMFTEvaluator` 的可靠度评估状态驱动重捕调度。
2. **两级分层搜索与防误劫持设计**：
   - **第一级：时空邻域重捕（Local Gating）**：处于 `TRACK_OCCLUDED` 状态（失锁 $1 \sim 15$ 帧），在卡尔曼外推中心为基准的动态邻域内匹配；
   - **第二级：全图无约束重捕（Global Search）**：处于 `TRACK_LOST` 状态（失锁 $> 15$ 帧），放开空间距离门限，增加**长宽比校验与连续两帧时序确认机制**；
3. **伺服软启动契约（机电防冲击）**：
   从 `TRACK_LOST` 重捕成功后，卡尔曼滤波速度直接归零，协方差矩阵重置为初始值，PID 彻底清空积分，防止瞬态大跳变产生虚假超大速度输出。

### 4.2 重捕判定与伺服平稳软启动实现规范 (`tryDetectAndRecover`)

```cpp
bool ObjectTracker::tryDetectAndRecover(const cv::Mat& image)
{
    if (!m_detector || !m_detector->isLoaded()) {
        return false;
    }

    std::vector<DetectionBox> detections = m_detector->detect(image);
    if (detections.empty()) {
        m_reacquireConsecutiveHits = 0;
        return false;
    }

    const float kfX = m_kf.x[0];
    const float kfY = m_kf.x[1];
    const float vx = m_kf.x[2];
    const float vy = m_kf.x[3];
    const float speed = std::sqrt(vx * vx + vy * vy);

    const float currentW = m_targetW * m_currentScale;
    const float currentH = m_targetH * m_currentScale;
    const float currentAspect = (currentH > 1.0f) ? (currentW / currentH) : 1.0f;
    const float origArea = std::max(16.0f, currentW * currentH);
    const float frameDiag = std::sqrt(static_cast<float>(image.cols * image.cols + image.rows * image.rows));

    const bool isTotalLost = (m_trackingState == AMFTTrackingState::TRACK_LOST) || (m_lostCount >= 15);

    // 第一级搜索半径随失锁时间与速度线性扩张；第二级搜索半径为全图对角线
    const float maxRadius = isTotalLost ? frameDiag : 
        std::min(frameDiag * 0.40f, std::max(currentW * 3.0f, speed * m_lostCount * 1.5f + 80.0f));

    // 全图检索提高置信度门限以抑制杂波虚警
    const float minConfThr = isTotalLost ? 0.35f : 0.25f;

    float bestScore = 0.0f;
    DetectionBox bestBox;
    bool found = false;

    for (const auto& det : detections) {
        if (det.confidence < minConfThr) continue;

        const float cx = det.rect.x() + det.rect.width() * 0.5f;
        const float cy = det.rect.y() + det.rect.height() * 0.5f;
        const float dist = std::sqrt((cx - kfX) * (cx - kfX) + (cy - kfY) * (cy - kfY));

        // 第一级距离拦截
        if (!isTotalLost && dist > maxRadius) continue;

        // 几何长宽比校验：抑制地面长条杂波（如路面白线、屋檐反光等极端高长宽比目标）
        const float detAspect = (det.rect.height() > 1.0f) ? 
            (static_cast<float>(det.rect.width()) / det.rect.height()) : 1.0f;
        const float aspectDiff = std::abs(detAspect - currentAspect) / std::max(currentAspect, 0.1f);
        if (aspectDiff > 1.5f) continue;

        // 面积与几何比率校验（全图丢失态放宽面积约束至 0.05x ~ 20.0x）
        const float detArea = static_cast<float>(det.rect.width() * det.rect.height());
        const float areaRatio = detArea / origArea;
        const float minAreaRatio = isTotalLost ? 0.05f : 0.20f;
        const float maxAreaRatio = isTotalLost ? 20.0f : 5.00f;
        if (areaRatio < minAreaRatio || areaRatio > maxAreaRatio) continue;

        float score = 0.0f;
        if (!isTotalLost) {
            const float distNorm = dist / maxRadius;
            const float distPenalty = std::max(0.0f, 1.0f - distNorm * distNorm);
            const float areaPenalty = std::min(areaRatio, 1.0f / areaRatio);
            score = det.confidence * distPenalty * areaPenalty;
        } else {
            // 全图检索打分：置信度 (60%) + 长宽比一致性 (25%) + 画面中心近邻度 (15%)
            const float centerX = image.cols * 0.5f;
            const float centerY = image.rows * 0.5f;
            const float distCenter = std::sqrt((cx - centerX) * (cx - centerX) + (cy - centerY) * (cy - centerY));
            const float centerWeight = 1.0f - (distCenter / frameDiag);
            const float aspectWeight = std::max(0.0f, 1.0f - aspectDiff * 0.5f);
            score = det.confidence * 0.60f + aspectWeight * 0.25f + centerWeight * 0.15f;
        }

        if (score > bestScore) {
            bestScore = score;
            bestBox = det;
            found = true;
        }
    }

    const float scoreThreshold = isTotalLost ? 0.35f : 0.20f;
    if (!found || bestScore < scoreThreshold) {
        m_reacquireConsecutiveHits = 0;
        return false;
    }

    // 全图检索增加时序双帧确认（防止单帧杂波突发劫持）
    if (isTotalLost) {
        m_reacquireConsecutiveHits++;
        if (m_reacquireConsecutiveHits < 2) {
            // 首次命中先记录临时坐标，暂不切换状态
            m_candidateBox = bestBox;
            return false;
        }
    }
    m_reacquireConsecutiveHits = 0;

    // 锁定目标并重置内核
    const cv::Rect newRoi(static_cast<int>(std::round(bestBox.rect.x())),
                          static_cast<int>(std::round(bestBox.rect.y())),
                          static_cast<int>(std::round(bestBox.rect.width())),
                          static_cast<int>(std::round(bestBox.rect.height())));
    const cv::Rect clampedRoi = newRoi & cv::Rect(0, 0, image.cols, image.rows);

    if (clampedRoi.width < 4 || clampedRoi.height < 4) {
        return false;
    }

    if (!reinitKernel(image, clampedRoi)) {
        return false;
    }

    m_posX = clampedRoi.x + clampedRoi.width * 0.5f;
    m_posY = clampedRoi.y + clampedRoi.height * 0.5f;
    m_targetW = static_cast<float>(clampedRoi.width);
    m_targetH = static_cast<float>(clampedRoi.height);
    m_currentScale = 1.0f;

    // 机电伺服平稳软启动机制：
    // 若从 TRACK_LOST 恢复，强制清零卡尔曼速度并重置协方差，杜绝超大速度跳变
    if (isTotalLost) {
        m_kf.x = cv::Vec4f(m_posX, m_posY, 0.0f, 0.0f);
        m_kf.P = cv::Matx44f::eye() * 8.0f;
    } else {
        kfUpdate(m_posX, m_posY);
    }

    m_evaluator.init(cv::Rect2f(clampedRoi.x, clampedRoi.y, clampedRoi.width, clampedRoi.height));

    return true;
}
```

## 六、 离线与实机验证规范

### 6.1 离线序列仿真验收
采用 `datasets/` 下的 Anti-UAV 评估序列与实录航拍视频执行回归测试：
1. **变倍序列测试**：模拟视距突变与尺度缩放（变化率 $> 200\%$）序列，输入 `ObjectTracker`，校验重校准后边界框相对真值误差 $\le 20\%$；
2. **大范围脱靶测试**：人工构造目标移出画面并在画面异侧重新出现的跳帧序列，注入 `ObjectTracker`，校验状态机从 `TRACK_LOST` 转入 `TRACK_REACQUIRED` 的耗时 $\le 300\text{ms}$（$\le 10$ 帧），且单帧杂波不会触发误重捕；
3. **伺服软启动测试**：校验脱靶重捕帧输出的 `kfVx` 与 `kfVy` 严格为 0，PTZ 输出速度不超过设定死区与比例初值。

### 6.2 实机飞行调试验收
1. **长时光学变焦闭环**：操控无人机处于悬停状态，上位机建立框选跟踪，按住变焦按键持续放大 3 倍，松开变焦按键后观察跟踪框是否在 1 帧内自适应重贴无人机外接矩形；
2. **脱靶再入闭环**：操控无人机快速机动飞出光电视场，上位机状态栏显示“目标丢失”，操控无人机重新飞入画面任意显眼区域，上位机应在 $1\text{s}$ 内自动弹出捕获框，且云台平稳启动跟随，无机械抖动甩动。
